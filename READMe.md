# The Timing Guess Game

A React-based timing challenge game where players test their ability to estimate time intervals. Players must stop the timer as close as possible to the target time to achieve the highest score.

## Features

- Multiple difficulty levels with different time challenges
- Real-time timer display
- Score calculation based on accuracy
- Player name customization
- Clean and modern UI with animations

## How to Play

1. Enter your name in the player section
2. Choose a challenge level:
   - Easy (1 second)
   - Not easy (5 seconds)
   - Getting tough (10 seconds)
   - Pros only (15 seconds)
3. Click "Start Challenge" to begin the timer
4. Try to stop the timer as close as possible to the target time
5. Your score is calculated based on how close you get to the target time

## Technologies Used

- React 19
- Vite
- React Portals
- CSS Animations
- React Hooks (useState, useRef)
